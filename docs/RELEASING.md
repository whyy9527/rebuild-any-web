# 源码与发行

`whyy9527/rebuild-any-web` 是唯一公开源码仓库。代码、技能、工作流、文档和测试在这里共同维护；组织副本使用 GitHub fork，由 fork 关系跟踪上游。

`pyproject.toml` 拥有版本，CHANGELOG 记录成果与限制。App 实现由独立产品仓库维护，`projects/` 仅包含合成协议夹具。

## 验证与发布

1. 按[环境说明](ENVIRONMENT.md)准备锁定环境，执行完整测试、真实无头浏览器检查和 `git diff --check`。
2. 核对本次精确文件、许可、文档链接和技能资源闭包，再提交、推送并确认远端提交。
3. 用户明确授权发行版本时，在本仓库发布对应标签与 Release。源码归档直接来自该标签；不再生成另一份源码仓库。
4. 组织 fork 通过正常的上游同步更新。核对其 `parent`、`source` 和分支提交，不建立独立快照或手工复制链路。
